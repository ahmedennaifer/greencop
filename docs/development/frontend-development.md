# Frontend Development

Develop the React dashboard.

## Tech Stack

- React 19.2.0
- TypeScript
- Vite
- TailwindCSS
- Recharts

## Development Server

```bash
cd web/frontend
npm run dev
# Opens on http://localhost:5173
```

## Project Structure

See architecture documentation for complete structure.

## Building

```bash
npm run build
# Output in dist/
```
